## 🔭 TechSheet — This Project

<div align="center">

[![forthebadge](https://forthebadge.com/images/badges/built-with-love.svg)](https://forthebadge.com)&nbsp;
[![forthebadge](https://forthebadge.com/images/badges/made-with-javascript.svg)](https://forthebadge.com)&nbsp;
[![forthebadge](https://forthebadge.com/images/badges/open-source.svg)](https://forthebadge.com)

</div>

**TechSheet** is a modern engineering blog platform built with Next.js + Tailwind CSS, featuring dark mode, Markdown-powered posts, and blazing-fast performance.

### ✨ Features

| Feature | Details |
|---------|---------|
| 🌙 **Dark Mode** | System-aware + manual toggle |
| 📃 **Markdown Posts** | Write once, ship anywhere |
| 🎨 **Tailwind CSS** | Utility-first, fully responsive |
| ⚡ **Next.js** | SSR + Static generation |
| 🚀 **Vercel Deploy** | Zero-config edge deployments |

### 🛠 Setup

```bash
# Clone & install
git clone https://github.com/thangamariappan19/techsheet.git
cd techsheet
npm install

# Run locally
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — you're live. ✅

To publish a post, drop a `.md` file into the `content/` folder following the standard frontmatter format.
